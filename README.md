## OverView

This project is a Nutrient Calculator written in excel. Not like other nutrient app, it allows you to acculately calculate your meal's nutrient base on the portion you consume.

## Installation

As said this nutrient calculator is written in excel. In order to use it, you must need to install window office with excel installed. This app used macros, therefore you need to have
macros installed or enabled in the excel. This nutrient calculator is developed on Micorsoft excel but also have tested on LibreOffice. LibreOffice compared to microsoft office is a free version. 

* Enable Macros on LibreOffice
    1. Go to Tools on the menu item
    2. Select Options
    3. Select Security
    4. Click on Macro Security on the left pane.
    5. For the Security Level tap, select "Medium" or "Low" for the option. 

## Config-Ussage

* For the app configuration. There are prdefined templates.

    1. Ingredient Template
        -  Don't corrupte this template. If you want to use it, add a new worksheet. For instance if you want to use it as breakfast, add a new worksheet, rename it to "Breakfast demo". And then copy the whole worksheet from the ingredient template to the new "Breakfast demo" worksheet. To copy the whole worksheet. Click on the left upper conner (you will see the arrow as shown on the image) and click "ctl + c" to copy it. Then on the "Breakfast demo" worksheet, click "ctl + v" to paste it. 
        - Fill in the nutrient data for the "breakfast", check on the breakfast demo.

        ![Alt text](./conner.png?raw=true)
        
    2. Menu Nutrient Record Template
        -  Don't corrupte this template. If you want to use it, select the relevant worksheet. For instance if you are working on "January", select "January Meal Record". Then to copy the whole menu nutient record template, click on the conner, the whole page will be selected then click "clt + c". To paste it to "January Meal Record", select the upper left conner and then click "clt + v" to paste it. On the cell "M3", please rename the worksheet for the first item from "Ingredient Template" to "Breakfast demo", the name should be the same as your ingredient worksheet you just newly added.
    3. Nutrient Total Template Daily
        -  Don't corrupte this template. Copy the whole page (by click on the upper left conner and click "clt + c"). Add a new sheet and rename it for example 'January Total daily' and selct the upper left conner 'clt v' to paste it. Rename the worksheet to point to your 'January Meal Record'. Click get total button, then it will sum up the nutrients for the whole day. 
    4. Nutrient Total Template Weekly
        -  Don't corrupte this template. Copy the whole page (by click on the upper left conner and click "clt + c"). Add a new sheet and rename it for example 'January Total weekly' and selct the upper left conner 'clt v' to paste it. Rename the worksheet to point to your 'January Meal Record'. Click get total button, then it will sum up the nutrients for the whole week.   
    5. Nutrient Total Template Monthly
        -  Don't corrupte this template. Copy the whole page (by click on the upper left conner and click "clt + c"). Add a new sheet and rename it for example 'January Total Monthly' and selct the upper left conner 'clt v' to paste it. Rename the worksheet to point to your 'January Meal Record'. Click get total button, then it will sum up the nutrients for the whole month. 
    6. Assesment Report And Chart
        - This is just a demo assesment report. It generates an assesment report base on your meal recorded. You can have the option to select either day, week or month. 
    6. Ussage
        - When finish adding the new record for a particular meal, don't forget to click on the "Complete" button to confirm. Please pay attention, when the "complete" button is clicked, all the data will be locked and setted. Any changes to the ingredients for the menu record will not be updated.  

## Potential-ussage

* There are a lot of potential ussage for this nutrient app. For example, you can use for analysing, cause we have recorded all your daily meal nutrient data plus the ingredients meal.
